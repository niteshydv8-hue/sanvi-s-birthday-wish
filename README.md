# Sanvi's Birthday Wish

Create a beautiful one-page birthday website for Sanvi ❤️.

Make it cute, aesthetic, emotional and slightly playful. Use a soft pink-purple gradient background, floating hearts, stars, sparkles, smooth animations and a premium glassmorphism design.

Hero section:
“Happy Birthday, Sanvi! 🎂❤️”
Subtitle:
“Today is special because someone very special was born today. ✨”

Add an animated birthday cake and a “Make a Wish 🎂” button. When clicked, show confetti and:
“May all your wishes come true, Sanvi! ✨”

Add a beautiful birthday message:
“Dear Sanvi, you may call me an idiot 😂, but today I just want to remind you how special you are. I hope this new year brings you endless happiness, beautiful memories, success and countless reasons to smile. Keep being your crazy, cute and amazing self. ❤️”

Add a Memories 📸 section with 3–4 photo placeholders and cute captions.

At the bottom add:
“One Last Surprise 💝”

When clicked, reveal:
“Happy Birthday, Sanvi! ❤️ You deserve all the happiness in the world. Keep smiling and keep shining! ✨🎂”

Add subtle background music with an ON/OFF button, but keep it OFF by default.

Make the website mobile-friendly, responsive, smooth, interactive and visually impressive. Use only HTML, CSS and JavaScript. Everything should fit into one single page.
